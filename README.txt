SITE "ANTES DO NOSSO SIM" - V2

Esta versão foi pensada primeiro para iPhone, em tela vertical.

1) MÚSICA
Coloque o arquivo da música que você tem na pasta principal do site e renomeie para:

musica.mp3

O site começa com o botão "Ativar experiência". Isso é proposital: no iPhone, o navegador costuma bloquear áudio automático antes de uma interação do usuário.

2) FOTOS
As 8 fotos estão na pasta /fotos e foram distribuídas sem repetir a mesma foto em telas consecutivas. Algumas telas não têm foto para criar ritmo e não deixar a experiência parecendo um álbum.

3) SENHA
18/04/2026

4) PROPOSTA
Na tela final aparece uma contagem e depois:
"Agora... não olhe para a tela."
"olhe para trás."

A ideia é você estar atrás dela, já ajoelhado com o anel, enquanto o fotógrafo grava.

5) COMO TESTAR
Abra index.html no navegador ou use uma extensão de servidor local no VS Code (por exemplo Live Server).

IMPORTANTE
Não coloque a música em um site público se você não tiver autorização para distribuí-la. Para o seu uso privado, mantenha o arquivo local no projeto.
